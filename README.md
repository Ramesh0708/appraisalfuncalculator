# HikeBoom: Appraisal Fun Calculator

Enter your last and current CTC to see your hike percentage, with a gauge, fun feedback and a "what's next" suggestion.

## Features
- Hike % calculated as `(current − last) / last × 100`
- Show/hide toggles for the CTC fields
- Optional job position and location
- Animated gauge and feedback for the result
- World map (Leaflet + OpenStreetMap)

## Tech stack
HTML, Bootstrap, CSS, vanilla JavaScript and Leaflet.

## Run
Open `index.html` in a browser (it needs internet access for the CDN libraries and map tiles). Everything runs in the browser, and no salary data is sent anywhere.
